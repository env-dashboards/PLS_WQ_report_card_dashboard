# Water Quality Dashboard

## Objective

Develop a proof-of-concept public-facing water quality dashboard for recreational waters.

The dashboard should demonstrate how weekly and monthly water quality data can be communicated through interactive visualisation and downloadable report cards.

## Inspiration

## Users

- Recreational users
- Event organisers
- Water quality scientists
- Asset managers
- General public

## Dashboard Sections

### 1 Overview

Display:

- Overall water quality grade
- Current status
- Traffic-light indicators

### 2 Trends

Display:

- Chlorophyll-a
- Enterococci
- Dissolved Oxygen
- Temperature
- Turbidity

Include:

- historical trends
- rolling averages
- guideline thresholds

### 3 Monitoring Sites

Provide:

- site map
- interactive site selection

### 4 Report Cards

Allow download of:

- weekly PDF report cards
- monthly PDF report cards

Historical report cards should remain accessible.

### 5 Future Enhancements

Potential future additions:

- 7-day algae forecast
- machine learning prediction
- automated alerting

## Technical Requirements

- Python
- Plotly
- Responsive design
- GitHub Pages compatible
